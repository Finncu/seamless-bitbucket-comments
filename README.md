# seamless-bitbucket-comments

IntelliJ-Plugin-Projekt fuer Bitbucket-Kommentar-Workflows.

## Projektstruktur

- `src/main/kotlin` - produktiver Kotlin-Code
- `src/main/resources` - Plugin-Metadaten und statische Ressourcen
- `src/test/kotlin` - Unit-Tests
- `gradle/` - Gradle-Wrapper

## Schnellstart

```bash
./gradlew test
./gradlew runIde
```
